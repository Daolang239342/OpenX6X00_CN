通用

配置工具可以更改的电台全部设置。

波段编辑器添加、更改和删除频段；启用选项可将某个频段绑定到上下切换键。
数字模式编辑器添加、更改和删除 FT8/FT4 及 JS8 的工作频率。
DX集群Cluster 应用使用的 Telnet DX 集群服务器。
遥控在浏览器中操作电台：实时屏幕、按键和旋钮、双向音频。可使用手机、平板电脑或 PC。
TCI 服务器为 VFO-Knob 和其他 TCI 客户端提供控制、仪表和音频功能：启用后设置其端口。
SSH 密钥允许通过 SSH 登录电台的密钥：可查看、添加和删除密钥。不接受密码登录。
更新从 GitHub 或软件包文件安装较新版本的 OpenX6X00，并支持自动回滚。
记忆读取、编辑和清空 MEM 存储位及命名频道。
文件浏览器从 SD 卡下载文件：ADIF 日志、屏幕截图和录音。
图库屏幕和接收录音、屏幕截图及缩略图；可在浏览器中将 AVI 转换为 MP4。
备份保存设置、存储频道、QSO 日志等内容，并可在刷入新镜像后恢复。
时间编辑器显示电台时钟，并可手动、通过 NTP 或时区设置时间。
