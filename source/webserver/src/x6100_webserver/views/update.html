更新

电台会自动安装较新版本的 OpenX6X00：包括 GUI、网页、辅助程序及其数据，来源可以是项目的 GitHub Releases 或软件包文件。文件会根据项目签名进行校验，并保留上一版本；安装结束后电台软件会重新启动（约一分钟）。如果新版本无法正常启动，会自动恢复上一版本。内核和 Wi-Fi 驱动仍需通过 SD 卡镜像安装。
